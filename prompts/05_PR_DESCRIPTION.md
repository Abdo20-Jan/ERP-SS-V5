# Prompt — Gerar descrição do PR

Gere a descrição do PR físico de `<SLICE_ID>` usando `.github/PULL_REQUEST_TEMPLATE.md`.

Inclua:
- propósito;
- requisitos atendidos;
- arquitetura e decisões;
- screenshots/evidências;
- migrations e rollback;
- testes executados;
- riscos e feature flags;
- checklist de segurança, auditoria, acessibilidade e offline;
- itens explicitamente fora do escopo.
