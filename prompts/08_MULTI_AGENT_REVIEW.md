# Multi-agent review

Review the branch against main.

1. `code_explorer` maps changed execution paths.
2. `pr_reviewer` finds correctness and regression risks.
3. `security` reviews relevant threat surfaces.
4. `testing_quality` checks coverage and evidence.
5. `requirements_traceability` checks accepted requirements.
6. `orchestrator` consolidates duplicate or conflicting findings.
7. Do not edit code during review.
8. P0/P1 findings block merge.
