# Base de fontes dos agentes

Este documento registra as fontes primárias e o uso adotado no pacote de agentes.

## Política

- Fontes externas sustentam práticas; decisões específicas do blueprint prevalecem dentro de seu campo, salvo obrigação normativa atual.
- Cada agente deve citar a tag da fonte no artefato de rastreabilidade quando a regra afetar a decisão.
- Regras normativas externas precisam de data de verificação antes da produção.
- Não declarar conformidade integral sem escopo, versão e evidência.
