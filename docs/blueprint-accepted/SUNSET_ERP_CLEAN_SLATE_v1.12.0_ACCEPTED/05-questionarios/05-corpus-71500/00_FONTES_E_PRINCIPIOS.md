# Fontes e princípios do corpus de 71.500 perguntas

As sugestões são orientações de discovery e desenho. Regras legais, fiscais e contábeis precisam ser validadas na vigência de implantação. As perguntas usam os IDs abaixo para registrar a base de cada recomendação.

## UX-01 — SAP Fiori — List Report
- **Fonte:** https://experience.sap.com/fiori-design-web/list-report-header-sap-fiori-elements/
- **Uso no corpus:** listas extensas, filtros únicos, variantes e tabelas personalizáveis.

## UX-02 — SAP Fiori — Object Page
- **Fonte:** https://www.sap.com/design-system/fiori-design-web/page-types/floorplans/object-page/
- **Uso no corpus:** objetos complexos com cabeçalho, ações, tabs e conteúdo responsivo.

## UX-03 — SAP Fiori — Worklist
- **Fonte:** https://experience.sap.com/fiori-design-web/work-list/
- **Uso no corpus:** filas acionáveis ordenadas por prioridade e próxima ação.

## UX-04 — SAP Fiori — Wizard
- **Fonte:** https://experience.sap.com/fiori-design-web/wizard/
- **Uso no corpus:** tarefas longas ou pouco familiares divididas em passos e revisão.

## UX-05 — SAP Fiori — Dynamic Side Content
- **Fonte:** https://experience.sap.com/fiori-design-web/dynamic-side-content-web-component/
- **Uso no corpus:** painel auxiliar sem tirar o usuário do contexto.

## UX-06 — GOV.UK — Error Summary
- **Fonte:** https://design-system.service.gov.uk/components/error-summary/

## UX-07 — GOV.UK — Check Answers
- **Fonte:** https://design-system.service.gov.uk/patterns/check-answers/

## UX-08 — W3C — WCAG 2.2
