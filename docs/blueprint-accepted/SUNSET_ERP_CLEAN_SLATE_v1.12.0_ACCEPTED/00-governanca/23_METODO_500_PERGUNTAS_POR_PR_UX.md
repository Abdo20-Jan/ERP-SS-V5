# Método das 500 perguntas por módulo e PR

## Interpretação de escopo

Foram criadas **500 perguntas no total**, distribuídas pelos 13 módulos e por **65 PRs propostos**. O objetivo é aprofundar o blueprint sem voltar ao modelo de milhares de perguntas desorganizadas.

## Estrutura obrigatória de cada pergunta

1. pergunta decisória;
2. sugestão recomendada;
3. exemplo aplicado à Sunset;
4. layout sugerido;
5. otimização de tempo e experiência;
6. critério de aceite;
7. fontes/princípios utilizados;
8. campo de confirmação ou alteração.

## Regra de uso

- Responder por PR, não necessariamente por módulo inteiro.
- Confirmar o PR completo quando todas as recomendações forem aceitas.
- Registrar apenas exceções quando houver divergência.
- Após resposta, converter o PR em especificação `BUILD-READY` detalhada: dados, APIs, páginas, permissões, eventos e testes.
- Nenhuma sugestão substitui validação fiscal, contábil ou jurídica quando a regra depender de norma externa.
