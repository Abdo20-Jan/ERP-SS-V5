# BOOT-01 — Tornar o scaffold executável

## Objetivo

Criar o primeiro PR físico do repositório, sem regra de negócio.

## Escopo

- inicializar pnpm workspace e lockfile;
- fixar versões compatíveis atuais;
- configurar Turborepo ou executor equivalente aprovado no plano;
- criar Next.js, NestJS/Fastify, worker e Tauri vazios;
- packages de config, contracts, db, domain, ui e testing;
- lint, formatter, typecheck, unit tests;
- CI mínima;
- PostgreSQL de desenvolvimento e migration zero;
- health endpoints;
- `.env.example`;
- README de execução.

## Fora do escopo

- lógica COMEX/fiscal/contábil;
- autenticação completa;
- deploy de produção;
- dados reais.
