# Checklist diário

## Antes de começar

- `git status` limpo;
- branch/worktree correto;
- main atualizado;
- slice e controller lidos;
- plano aprovado;
- nenhum segredo no contexto.

## Antes de parar

- testes relevantes executados;
- rastreabilidade atualizada;
- diff inspecionado;
- risco/migration/rollback anotados;
- sem arquivo gerado acidentalmente;
- próximo passo registrado no chat e no PR.
