# Insumos de referência

Esta pasta preserva os arquivos enviados na conversa atual que serviram como amostra de operação, respostas de levantamento, balanço e referências visuais.

- Nenhum repositório GitHub foi usado como fonte de requisitos.
- As imagens são referências de padrões de informação e experiência; não constituem telas a copiar literalmente.
- A planilha de balanço é uma amostra de saída e reconciliação, não o modelo de dados do ERP.
- Em caso de conflito, aplica-se `docs/governance/DECISION_PRECEDENCE.md`.
